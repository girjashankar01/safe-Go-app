# SafeGo UI v2 – Implementation Rules

## General Rules

- UI refactor only.
- Do not change business logic.
- Do not modify backend APIs.
- Do not duplicate services.
- Reuse all existing functionality.
- Reuse existing screens whenever possible.
- Reuse existing navigation destinations.
- Complete only the current phase.
- Ignore future phases.
- Leave the project in a fully working state after every phase.

## If a requirement conflicts with existing functionality

Preserve existing functionality.

Prefer adapting the UI rather than changing business logic.

## If uncertain

Inspect the codebase first.

Reuse before creating.

Never assume.
